# Site Directory

Curated design inspiration and visual-asset sources, organized by task.
Cross-checked against 2026 design-inspiration roundups; mainstream sites verified live.

## Aggregators
- [Designeer](https://www.designeer.xyz) — design/UI resource directory, agent-friendly (llms.txt / MCP). Start here: Inspiration gallery.
- [Muzli](https://muz.li) — design news aggregator (browser extension), daily feed.

## Web design galleries (overall style / cover mood)
- [Awwwards](https://www.awwwards.com) — daily award-winning sites, cutting-edge experimental (use sparingly for understated brands)
- [SiteInspire](https://www.siteinspire.com) — hand-curated real live websites, filter by style/type/subject
- [Lapa Ninja](https://www.lapa.ninja) — landing page gallery, filter by category/color/style
- [Land-book](https://land-book.com) — landing page + website gallery, clean browsing
- [Httpster](https://httpster.net) — clean modern web showcase
- [Minimal Gallery](https://minimal.gallery) — minimalism
- [Dark Mode Design](https://www.darkmodedesign.com) — dark-mode showcase
- [Recent](https://godly.website) — (formerly Godly) premium visual/branding/motion
- [The FWA](https://thefwa.com) — veteran digital creativity awards
- [CSS Design Awards](https://cssdesignawards.com) — CSS/technique-focused awards
- [One Page Love](https://onepagelove.com) — single-page websites
- [Designspiration](https://designspiration.com) — general inspiration, design-focused Pinterest alternative
- [Pinterest](https://www.pinterest.com) — universal mood boards; the more specific the keywords, the better

## Landing / section libraries (concrete layouts: hero / CTA / footer / nav)
- [Landingfolio](https://www.landingfolio.com) — landing pages by industry and page type
- [Unsection](https://www.unsection.com) — real website sections shown separately (hero / CTA / footer / nav)
- [Footer.design](https://www.footer.design) — footer designs only
- [Navbar Gallery](https://www.navbar.gallery) — navigation bar designs only

## Mobile UI / real product screenshots (vertical covers, card layouts)
- [Mobbin](https://mobbin.com) — real app screenshot library, filter by app/flow/screen type (partly paid)
- [before.click](https://before.click) — App Store screenshot inspiration, vertical card stream, "big title first" cards
- [Screenlane](https://screenlane.com) — mobile UI inspiration
- Refero — real product screenshots by company/page type/component (search the name)
- Page Flows — recorded user flows: onboarding, checkout, etc. (search the name)

## Design communities
- [Dribbble](https://dribbble.com) — designer shots, concept-heavy
- [Behance](https://www.behance.net) — Adobe's platform, full project case studies (good for the *why* behind a design)

## Typography
- [Fonts In Use](https://fontsinuse.com) — typefaces in real-world use
- [Practical Typography](https://practicaltypography.com) — typography rules handbook (paper-feel, serif)
- [Google Fonts](https://fonts.google.com) — free font library
- [Fontshare](https://www.fontshare.com) — free high-quality fonts

## Color / backgrounds / textures
- [Coolors](https://coolors.co) — palette generator
- [Realtime Colors](https://www.realtimecolors.com) — palette previewed live on a page
- [Huemint](https://huemint.com) — color + font pairing
- [MagicPattern](https://www.magicpattern.design) — background pattern generator
- [Haikei](https://haikei.app) — waves / blobs / gradient SVG generator
- [Backgrounds Supply](https://backgrounds.supply) — dark atmospheric textures + gradient lab
- [Heropatterns](https://heropatterns.com) — SVG texture patterns

## Icons
- [Lucide](https://lucide.dev) — open-source icons
- [Heroicons](https://heroicons.com) — Tailwind-style icons
- [Phosphor](https://phosphoricons.com) — thin-line icons

## Stock photos (card art / backgrounds)
- [Unsplash](https://unsplash.com) — free high-quality photography
- [Pexels](https://www.pexels.com) — free photos + videos

## Usage order (avoid choice paralysis)
1. Set the style → brand preset (or Designeer picks)
2. Find the layout → section libraries (Unsection, Landingfolio)
3. Find the elements → type / color / icons / textures
4. Settle on 2–3 go-to sources; don't hoard
